# Third-party notices

Anomaly Zoo itself is MIT licensed (see `LICENSE`). This file lists the third-party code it ships or builds with, with exact versions and licenses. It is generated by `scripts/gen-third-party-notices.mjs` from `web/package-lock.json`, the installed packages and the Go module cache; CI fails if it is stale. Do not edit it by hand.

## What reaches a visitor's browser

* The static pages are built by Next.js from React components; the browser receives the compiled application bundle, which contains code from **next**, **react** and **react-dom** (their exact versions are in the table below) and from the project's own source.
* The calculation engine is the project's own Go code compiled to WebAssembly with the Go toolchain **go1.27.3**. The WebAssembly module therefore contains the Go runtime and standard library, which are BSD-3-Clause licensed, and the page loads `wasm_exec.js` from the same toolchain (also BSD-3-Clause).
* **Fonts:** none are shipped. The site uses system font stacks, so there are no font files to attribute.
